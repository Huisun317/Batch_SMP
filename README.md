# Batch_SMP
This repository contains sample code from the paper *Batch Sample-wise Stochastic Optimal Control via Stochastic
Maximum Principle*. where we 

* **Improve the accuracy and efficiency of the algorithm by using Batching and higher order accuracy of the scheme**

*  **Proposed a new algorithm (dampped contraction) which leverages both the necessary and sufficient condition of the SMP**

* **Show how to combine the idea (currently only projection) with DNN and use it to solve a high dimensional PDE**
